4. Create new variables with case_when

Create the daily_death variable.

Classify daily deaths as low, medium, or high.

library(dplyr)

df$daily_death <- case_when(
  is.na(df$deathIncrease) ~ NA_character_,
  df$deathIncrease < 3 ~ "low",
  df$deathIncrease <= 14 ~ "medium",
  TRUE ~ "high"
)

table(df$daily_death)

  high    low medium 
  7092   7903   5785

Create the month2 variable.

  • early_month: days 1–10
  • mid_month: days 11–20
  • end_month: days 21–31
df$month2 <- case_when(
  df$monthday <= 10 ~ "early_month",
  df$monthday <= 20 ~ "mid_month",
  TRUE ~ "end_month"
)

table(df$month2)

       6934        7087        6759

Create the weekend variable.

Assign 1 to Saturday and Sunday and 0 to other days.

df$weekend <- case_when(
