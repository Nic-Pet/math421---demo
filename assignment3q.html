  1. Create the categorical variable death3 variable taking the values as follows

  • low_death if the number of deaths smaller than the 25 percentile (Q1)

  • mid_death if the number of deaths from Q1 to Q3

  • high_death if the number of deaths greater than Q3

library(dplyr)

q <- quantile(df$deaths, probs = c(0.25, 0.75), na.rm = TRUE)

df$death3 <- case_when(
  df$deaths < q[1] ~ "low_death",
  df$deaths >= q[1] & df$deaths <= q[2] ~ "mid_death",
  df$deaths > q[2] ~ "high_death"
)
